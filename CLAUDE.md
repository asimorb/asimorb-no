# Asimorb Works Website

This is a simple one-page personal works website for @asimorb.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Static one-page site for now

## Design direction

- Minimal white background
- Serif typography
- Use Georgia, "Times New Roman", Times, serif
- Sparse archival layout
- Inspired by ethanchng.com but not copied exactly
- Intro at top
- Contact links as a numbered list
- Left category column on desktop
- Main works column scrolls normally
- Left category column stays sticky on desktop
- Any parallax should be extremely subtle
- On mobile, no sticky sidebar; everything stacks vertically
- Large light-grey project cards
- Thin divider lines
- No CMS
- No project pages yet
- No animation libraries
- No unnecessary dependencies

## First build goal

Build only the static homepage.
